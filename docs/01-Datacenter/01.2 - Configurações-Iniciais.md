# Configurações Iniciais

## Objetivo

Realizar as configurações básicas do sistema operacional após a instalação.

## Configurações realizadas

### Criação de usuários 

Decidi criar dois usuários para o sistema: "voyager" e "octavio". O usuário chamado "voyager" foi criado com a intenção de ser um usuário comum padrão.

Ele não possui privilégios administrativos e serve apenas como usuário de transição, para que a partir dele eu transite para o usuário "octavio", que será o usuário utilizado para administração do sistema, com permissão para virar root.

O motivo dessa abordagem é adicionar uma camada extra de segurança. A ideia é configurar futuramente o OpenSSH para bloquear o login como root e permitir login apenas por esse usuário, exclusivamente por autenticação via chave.

Dessa forma, caso ele seja comprometido de alguma forma, o invasor teria ações limitadas no servidor. Ele ainda precisaria obter as credenciais do usuário "octavio" para conseguir privilégios administrativos.

Futuramente pretendo evoluir a configuração.

### Hostname

O hostname do servidor foi definido como "sol".

Eu escolhi esse nome porque pretendo fazer uma organização baseada no sistema solar. O servidor principal recebe o nome "sol", enquanto os demais servidores utilizarão nomes de planetas. 

### Convenção adotada

- sol (servidor principal)
- terra (planejado)
- marte (planejado)
- júpiter (planejado)

### Atualização do sistema

Realizei as atualizações básicas do sistema após a instalação.

### Personalização do bash dos usuários

Costumo sempre colocar uma personalização dentro do .bashrc dos meus usuários. Ela basicamente habilita cores no comando ls para facilitar a identificação de arquivos e diretórios, e faz com que o prompt do terminal mostre o usuário, o nome da máquina e o diretório atual em cores diferentes.

Também coloquei alguns aliases que facilitam meu uso no sistema no dia a dia. 

### Sincronização de data e hora

O RHEL e seus derivados vêm por padrão com o Chrony instalado e pré-configurado. As únicas alterações realizadas foram a mudança dos servidores de sincronização. 

Configurei os servidores a, b e c do projeto NTP.br e adicionei as opções `iburst` e `nts`.
