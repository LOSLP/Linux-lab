# Instalação do Datacenter

## Objetivo

Preparar o servidor principal do laboratório.

## Ambiente

- IaaS - Contabo
- CPU: 4 vCPUs
- Memória: 8 GB
- Armazenamento: 150 GB
- Imagem: Rocky Linux 9.8 (Minimal)

## Configurações escolhidas

### Tipo de instalação

Minimal Install

### Particionamento

Automático

### Criptografia

Desabilitada

### Usuário root

O usuário root foi habilitado para login. A senha foi configurada durante a instalação.

### Usuário padrão

Não criado.

## Motivo das escolhas

Como o objetivo do laboratório é desenvolver habilidades de administração Linux, optei por realizar as configurações manualmente após a instalação, reduzindo a quantidade de componentes instalados inicialmente e mantendo o ambiente mais próximo de um servidor em produção.
